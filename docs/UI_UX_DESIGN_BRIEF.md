# UI/UX Design Brief
## NetworkOps — Same Hyperstudio Theme

Same monochrome terminal + amber design as VAPTLearn and GRCLearn for portfolio cohesion.

**Source:** https://styles.refero.design/style/8eb9c53e-d69c-497a-b640-610856cf3a60

Colors: Midnight #101010, Carbon #333333, Ash #949494, Polar #F3F3F3, Amber #E7C59A, Green #00AC5C
Fonts: Inter (UI), JetBrains Mono (code/commands)
Radius: 8px default, 20px tags
No shadows. Dark shades for depth.

### Quiz-Specific Components
- **Answer input:** Full-width textarea with monospace font for commands
- **Correct indicator:** Green border + checkmark
- **Incorrect indicator:** Red border + explanation
- **Hint button:** Amber ghost button
- **Progress bar:** Thin amber bar showing question X/N
- **Score card:** Green/Red ratio visualization
